# PBSA Logistics – Corporate Website

This is the official corporate website for PBSA Logistics, developed as part of the XISD5319 project.

## Live Demo


## Technologies
- HTML5, CSS3, JavaScript
- FontAwesome for icons
- Google Fonts (Montserrat, Open Sans)

## Pages
- Home
- About
- Services
- Accreditations
- Contact
- Quote Request
